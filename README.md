# Estructura de Datos: La Base Fundacional de la Ingeniería de Ciencia de Datos

Hola estudiante de Ingeniería de Ciencia de Datos de la Universidad del Magdalena. Bienvenido a tu guía de estudio de Estructura de Datos.

La modernidad se mueve con datos, y la ingeniería de ciencia de datos es lo que le da sentido a esos datos. Manipular grandes volúmenes de información es un proceso complejo, y no todas las situaciones requieren la misma solución. Es por ello que existen las estructuras de datos, que sirven como marcos de trabajo para organizar y manipular la información de forma eficiente.

El propósito de este repositorio es ayudarte a entender cómo se aplican realmente las estructuras de datos en escenarios reales de ingeniería. No buscamos que construyas las estructuras desde cero reinventando la rueda, sino que aprendas a caracterizarlas, entender su comportamiento en memoria y saber cuándo, cómo y por qué elegir la estructura adecuada para cada problema.

Por convención, en el curso trabajaremos con el lenguaje de programación C#.
