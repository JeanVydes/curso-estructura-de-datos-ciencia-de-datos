# Estructura de Datos: La base fundacional de la ciencia de datos

La modernidad se mueve con datos, y la ciencia de datos es lo que le da sentido a esos datos, pero manipular datos es un proceso complejo, y no siempre es lo mismo, ni tiene las mismas finalidades, es por ello que existen las estructuras de datos, que sirven como marcos de trabajo para manipular datos de una manera conveniente.

Este repositorio tiene como finalidad dar a entender como es que las estructuras son aplicadas realmente en la vida real a traves de la ciencia de datos. No buscamos implementar las estructuras desde cero, sino caracterizarlas, entenderlas y saber cuando, como y por que elegir cada una de ellas.

Esta guia pertenece y se crea a partir de la iniciativa de enseñar a estudiantes de Ciencia de Datos en la Universidad Del Magdalena. Por convencion internamente utilizaremos codigo en C#.
